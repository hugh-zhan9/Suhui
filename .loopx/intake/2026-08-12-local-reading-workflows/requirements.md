# 本地阅读工作流增强需求

## Canonical Goal

在完全本地的 Suhui Desktop 数据面上交付五项互相兼容的能力：可恢复备份与本地 OPML、重复内容聚类、规则引擎、本地笔记与高亮、独立阅读队列；Desktop 与 Remote 共用主进程应用服务和 PostgreSQL 真相源。

## Scope

- 版本化完整备份、校验、合并恢复、完整替换恢复与失败回滚。
- 完全本地 OPML 解析、选择性导入和导出。
- 对新抓取文章计算重复聚类，列表折叠并可展开来源。
- 按来源和标题关键词匹配的新文章规则，以及历史预览/确认执行。
- 文章级本地标签，供规则动作、手动维护、筛选和搜索使用。
- 逐篇多笔记、高亮创建/删除、重新定位与失效状态。
- 与已读、收藏独立的稍后读队列、完成记录、积压量和进度。
- 新数据纳入完整备份；笔记和高亮纳入本地搜索数据源。

## Non-goals

- 删除重复文章或合并逐篇用户状态。
- 云端同步、多人协作或跨设备实时冲突合并。
- 自动摘要、在线 AI 聚类或语义向量服务。
- 本期实现通用布尔表达式规则语言；规则条件限定为来源集合和标题关键词。
- OPML 携带正文、阅读状态、笔记或规则。

## Acceptance Criteria

- **AC-001**：完整备份采用可版本化文件格式，导出覆盖订阅/分类、文章及正文缓存、读状态、收藏、规则、聚类、笔记、高亮、阅读队列和相关本地设置，并能在导入前完成结构与校验验证。
- **AC-002**：合并恢复不删除当前数据；完整替换恢复必须先创建安全快照、要求显式确认，并在任何导入步骤失败时恢复到操作前状态。
- **AC-003**：OPML 导入和导出完全在本地完成；导入可预览并选择订阅，重复订阅不产生第二份；导出保留分类。
- **AC-004**：相似文章被分配到可重算的聚类，普通列表只折叠展示代表条目并显示来源数，用户可展开全部版本；任何原始条目和逐篇状态均不被删除或共享。代表项优先使用用户手动选择，其次使用有用户投入的版本，再按正文完整度和最早发布时间稳定选择。
- **AC-005**：规则支持来源集合、标题关键词、启用状态，以及自动已读、加星、加入稍后读、添加文章标签和隐藏动作；新抓取文章在持久化后执行启用规则。文章标签不得修改订阅分类。
- **AC-006**：规则不会因创建或编辑而自动改写历史文章；历史应用必须先返回预览数量并由用户确认。隐藏文章不出现在普通列表，但仍能通过搜索和规则管理访问。
- **AC-007**：一篇文章可保存多条本地笔记和高亮；高亮记录原文、前后文、正文类型与位置提示，正文变化时可重新定位，失败时保留且标记失效。
- **AC-008**：笔记、高亮和文章标签绑定具体 `entryId`，不跨重复聚类自动共享，并包含在完整备份与本地全文搜索数据源中。
- **AC-009**：稍后读状态与已读、收藏独立；加入、完成、重新加入和移除均可用，显式完成会留下完成时间；UI 显示待阅读积压量和分时段完成数。
- **AC-010**：Desktop 与 Remote 对日常阅读工作流使用同一应用服务和数据库事务语义；现有订阅、刷新、阅读、已读、收藏和分页行为保持兼容。完整备份仅通过 Desktop 暴露；在 Remote 最小鉴权落地前，规则、标签、隐藏、聚类人工决策、笔记、高亮和阅读队列 HTTP 接口仅允许 loopback 访问，LAN/VPN Remote 仍提供不含阅读私密数据的 OPML。
- **AC-011**：所有 schema 迁移可在已有数据库上安全执行；派生聚类可以重建，用户创建的规则、笔记、高亮和队列状态不得被重建过程覆盖。

## Acceptance Scenarios

- **TC-001（AC-001, AC-002）**：导出完整备份，在含额外本地数据的数据库中执行合并恢复，额外数据保留；注入恢复失败后数据库与操作前快照一致。
- **TC-002（AC-002）**：未确认时拒绝完整替换；确认后恢复出的核心表计数与备份 manifest 一致。
- **TC-003（AC-003）**：离线环境导入含分类和重复 URL 的 OPML，预览正确，选中项只新增缺失订阅；随后导出可被标准 XML 解析器读取。
- **TC-004（AC-004）**：两篇跨源转载文章形成同一聚类，列表显示一个代表项和两个来源；展开后两个条目仍保有不同已读/收藏状态。
- **TC-005（AC-005, AC-006）**：启用规则后新文章按来源与标题命中并执行动作；旧文章不变，历史预览不写库，确认应用后才写入。
- **TC-006（AC-006）**：隐藏文章从普通时间线消失，但搜索和规则历史结果仍能返回该条目。
- **TC-007（AC-007, AC-008）**：创建笔记和高亮后刷新 readability 正文，高亮能重新定位；无法定位的高亮显示失效且原始内容仍可查看，备份恢复后保持一致。
- **TC-008（AC-009）**：未读文章加入稍后读后标记已读仍留在队列；显式完成后积压量减少、完成数增加；重新加入后恢复为待阅读。
- **TC-009（AC-010, AC-011）**：Desktop 和 Remote 对同一笔记/队列/规则变更读取一致；既有数据库迁移后原有订阅、条目、收藏和已读状态不变。

## Evidence Targets

- 应用服务与数据库服务单元测试。
- PostgreSQL 迁移和真实数据库集成测试。
- Desktop/Remote transport parity 测试。
- OPML XML fixture、备份 round-trip 与失败回滚测试。
- Renderer 交互测试和全仓 `pnpm test`、`pnpm typecheck`。
